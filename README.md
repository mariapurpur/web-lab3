# 2048

Стайрешая классика веб-игр: 2048.

## Функционал

- Игровое поле 4х4 с объединением плиток;
- Возможность отмены хода;
- Таблица лидеров с лучшим счётом;
- Сохранение прогресса в localStorage.

## Используемые языки

- HTML
- CSS
- JavaScript

## Запуск

Откройте файл `index.html` в браузере или откройте сайт через GitHub Pages.
